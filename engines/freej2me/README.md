# FreeJ2ME Web Engine

Tempatkan file build dari repositori `freej2me-web` di folder ini:
- `freej2me-web.js`
- `freej2me-web.wasm`
- `freej2me-web.data` (jika ada file data JDK/J2ME runtime)
- File index atau wrapper kanvas pendukung

Struktur umum:
```
engines/freej2me/
├── freej2me-web.js
├── freej2me-web.wasm
├── freej2me-web.data
└── README.md
```
